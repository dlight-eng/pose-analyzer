# Аналізатор робочої пози

Вебінструмент для ергономічної оцінки робочих операцій за відео: скелет поверх кадру, кути суглобів, бал REBA, ризики й рекомендації, порівняння «до/після», звіт PDF.

Відео обробляється в браузері користувача й нікуди не передається.

## Що вміє

- Розпізнавання пози (MediaPipe Pose) і кути тулуба, шиї, плеча, ліктя, коліна
- REBA для кожного кадру за таблицями A, B, C; форма для даних, яких не видно на відео
- Ризики та рекомендації за правилами
- Цикли й хронометраж, карта навантаження тіла, навантаження за зміну і рік
- Порівняння «до/після», картка одним зображенням, звіт PDF, запис відео зі скелетом
- Приховування облич
- Встановлення на телефон як застосунок і робота офлайн після першого аналізу

## Розгортання на GitHub Pages

1. Settings → Pages → Build and deployment → Deploy from a branch.
2. Гілка `main`, папка `/ (root)`, Save.
3. За хвилину-дві сайт відкриється за адресою `https://<користувач>.github.io/<репозиторій>/`.

Збірка не потрібна: це статичні файли.

## Структура

- `index.html` — увесь інтерфейс і логіка
- `mp/` — модель і бібліотека MediaPipe Pose (двійкові файли запаковані в JSON як base64)
- `sw.js`, `manifest.json`, `icon-*.png` — офлайн-режим і встановлення як застосунку

## Обмеження

- Оцінка двовимірна: знімати треба збоку, людина на повний зріст. Скручування тулуба, зап'ястя та вага вантажу вводяться вручну.
- Таблиці REBA та пороги варто звірити з ручною оцінкою перед використанням у звітах для клієнтів.
- Результат є скринінгом і не замінює огляд робочого місця фахівцем.

## Ліцензії

MediaPipe Pose поширюється за ліцензією Apache 2.0.
